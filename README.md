# Regenerative Harvest Planning

Project 2 of a two-project geospatial portfolio piece on Finnish forestry. This
repository operationalises the Finnish harvest-window problem and a published
regenerative-forestry programme for one mill procurement area: a date-specific
wetness and trafficability surface (Module D), a per-stand site plan (Module E),
and a biodiversity connectivity prioritisation (Module F). Companion repository:
`boreal-stand-intelligence` (Project 1, complete). This README is a stub and
will be written in full once the modules are complete, in the same figure-led,
per-module style as Project 1's.

Contains data from the Finnish Forest Centre, licensed CC BY 4.0. Contains
Natural Resources Institute Finland MS-NFI and DTW data, CC BY 4.0. Contains
data from the National Land Survey of Finland, CC BY 4.0. Contains Finnish
Meteorological Institute open data, CC BY 4.0. Contains data from the Finnish
Environment Institute (SYKE), CC BY 4.0.
